# 오사카 맛집 지도

난바·닛폰바시·도톤보리·신사이바시와 오사카역·우메다·기타신치 일대의 식당을 찾아보는 모바일 정적 웹페이지입니다. 빌드나 API 키가 필요 없습니다.

## 목록 기준

- 2026년 11월 19일 확인한 타베로그 지역·역·장르의 공개 평점순 목록을 합쳤습니다. 평점 3.50 이상이며 타베로그 식당 페이지가 확인된 곳을 수록했습니다.
- 같은 매장이 여러 장르로 등록되어 있으면 각 장르에 포함합니다. 장르를 선택하면 현재 지역·예산 등 조건에 부합하는 식당을 평점순으로 최대 20곳 선정합니다. 평점 동점은 표시 상호순으로 정렬합니다.
- 타베로그 1인 예상 지출 범위를 표시합니다. 기본 예산은 저녁을 우선하고 저녁 정보가 없으면 점심을 사용합니다. 범위에 1만 엔이 들어 있으면 이하와 이상 필터 양쪽에서 볼 수 있습니다.
- 타베로그 어워드 수상점에는 ‘추천’을 표시합니다. 백명점과 주소·상호를 확인한 미쉐린 2026 선정점은 별도 배지로 표시합니다.

`restaurants.js`에서 장르와 식당 데이터를 관리합니다. `index.html`을 브라우저에서 열어 확인할 수 있으며, GitHub Pages는 `main` 브랜치 루트에서 게시합니다.
